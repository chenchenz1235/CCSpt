# fct-production · 产线 FCT 工装编制

试用技能，维护人：[@chenchenz1235](https://github.com/chenchenz1235)。发布快照：2026-10-27。

适用于基本功能正常的控制板、电机驱动板，根据完整原理图、PCB 和固件编制产线 FCT 方案。不用于整机性能或老化验证。

## 使用流程

1. 确认项目总览及检测项目。
2. 规划检测阶段，对比当前协议和代码能力，确认软件配合方案。
3. 沿用模板交付测试点表、测试流程、通信协议、软件修改指导及检查表。

软件修改后的核对按需开展；默认提出修改建议，不自动修改固件。资料完成、代码实现、编译结果和实机验证分别记录。

## 安装与调用

将本目录整体安装为宿主的 `fct-production` 技能目录，保留 `SKILL.md`、`agents/`、`references/` 和 `assets/` 的相对结构。Codex 默认位置为 `~/.codex/skills/fct-production/`；已有同名技能先比较并备份。

支持 GitHub skill 安装的宿主可使用源仓库 `chenchenz1235/CCSpt`、路径 `labs/skills/fct-production`，选定所需提交版本安装。本技能属于试用区，不加入正式技能的默认安装集合。

调用示例：

> 使用 $fct-production，根据我提供的原理图、PCB 和固件，先开展第一步项目总览与检测项目确认；已有模板请沿用。

提供完整原理图、PCB 原文件、完整固件；已有工装表格和协议可一并提供。没有自有模板时使用内置清洁模板。运行任务的 AI 需能读取相关工程文件，并具有 XLSX/DOCX 编辑及渲染能力；没有这些能力时应说明未完成的交付项。
