# 测点、表格和协议

## 6 测试点怎么找

按已确认测项在PCB原文件中选取合适接点，写清器件脚、参考端和板面；仅在必要时给备选。先决定项目是否需要物理接触。协议回传的内部ADC不额外增加采样针；工装需要的是外部激励端、供电端、通信端和必要的参考端。

定位顺序：从原理图确认功能节点及网络→在PCB中追踪同网对象→优先选择PCB背面裸露金色测试点→没有硬件规划的测试点时选同网端子焊盘（梅花针）→核对网络、板面、尺寸、阻焊开窗、中心距、器件和装配遮挡。产线只能扎一面，默认所有针点统一在背面，不能混选正反面；金色外观不能单独证明网络或可扎针性，应结合PCB和实板/制造资料核实。相邻所选针点中心距≥2.5mm；专用测试点推荐直径1.5mm，最小1.2mm，仅局部受限点采用1.2mm，不能全部采用最小尺寸。主要供电可通过端子连接。没有硬件规划的测试点时，允许用端子焊盘扎针，工装选用梅花针；端子焊盘须位于同一扎针面，且与其他所选针点的中心距均须≥2.5mm。核实焊盘尺寸、焊接状态及梅花针接触空间，不因其不是金色专用测试点而排除。测试点表写明端子位号、脚号、参考端和“端子焊盘／梅花针”；通过端子插接而不扎针的接线仍只写入配置及流程。

需要电气等价才能替换：不能跨电阻、滤波器、采样元件、继电器或隔离器任意换点。端子同名功能不等于同一网络，电源负端也不一定可互换。

正式测点采用“真实网络名 / 参考端”或“器件位号-具体脚号 / 参考端”。例如“NetD1_A / GND（K2-4同网焊盘）”“C91-1 / GND（信号侧）”。辅助图可编定位索引，但不得把自编A01、P01冒充PCB原有TP编号，也不拿它替代正式测点名称。

专用测试点和备选端子焊盘均找不到符合单面、适配尺寸及中心距要求的针点时，列明网络、现有位置与不符合项，提出背面新增/调整测试点的硬件整改建议；未落实的点不能标为可加工针点，也不能用顶面器件脚补齐背面针床。若需整体改换扎针面，须明确确认，仍只允许单面。普通覆盖阻焊的过孔不能直接视为可扎针点。尺寸、间距或表面状态缺少依据时标待核实，不凭图片估算后宣称达标。

仅在用户需要针床坐标或定位图时另交附件，至少包含：真实网络、参考器件脚、板面、X/Y、单位、原点、观察方向、焊盘尺寸、机械可达性状态。必须说清底面坐标是否镜像；没有确认转换前，辅助图坐标不能直接当加工坐标。GND、VDC−、隔离EGND、PE分别确认。

### 供电与测量的隔离说明

逐个供电回路和测量通道分别写明“相对主供电隔离”或“相对主供电非隔离”，以及接入网络、正负端/测量参考端、工装通道和允许的共地关系。需要隔离的辅助供电须明确独立隔离输出及其回路参考端；需要隔离的测量须明确隔离测量通道/仪表及隔离边界。二者分别判断，不能因供电已隔离就默认测量也隔离，不能把普通差分输入视作隔离输入。

非隔离项也须写出实际共地节点；GND、VDC−、EGND和PE不可按名称直接短接。核对仪表公共端、通信适配器及辅助电源是否跨接隔离域。供电/测量是否需要与主供电隔离必须由实际电路和工装接法支持；依据不足时写具体待核实项，不默认可共地。扎针相关要求写入测试点表既有备注或配置栏，端子等非扎针接线写入接线配置；流程引用配置并写清上电、切换和撤除时序。

## 7 测试点表和流程表怎么填

### 测试点表

本表交工装工程人员落实针床，只列实际扎针的信号、供电及参考端。纯协议读取、端子插接供电、端子连接的通信/负载等不单独列为测试点；需要扎针的外部激励或通信端仍应列入。不扎针不等于不测试，其连接、动作及判据在流程或配置与判限页完整说明。

|栏目|填写内容|避免的写法|
|---|---|---|
|测试项目|一个明确对象及必要通道|“电流检测”却未区分主/风机或相位|
|测试方法|前置状态、激励、读取或测量动作|只写“正常”“检测”|
|测试点|实际扎针点、参考端、统一板面及尺寸/间距；参考端需扎针时同样落实|只写MCU引脚、虚构TP、为所有内部ADC增加针|
|测试范围|统一“理论：…；范围：…”；数值含单位/容差，状态含预期组合与通过条件；未定标待确认|混用AD/V/A、0～1和0～100、理论中心值充当完整判限|
|备注|检测类别；供电与测量各自的隔离/非隔离关系、参考端及配置引用|按“是否发过命令”决定类别|

测试范围逐项写两段“理论：…”和“范围：…”。单位服从协议：回传V则写5V，回传AD则写“1755 AD（5V）”，不要因为载体是float改变单位。状态类理论写期望状态，范围写允许状态组合；未知LED压降等明确待确认，不编造理论或限值。

用户默认容差（项目明确指定值优先）：

|对象|理论与范围|
|---|---|
|VAC、VDC等电压协议对比|理论为同一物理对象的工装实测/已确认目标值U；范围U−5～U＋5V。不能混淆线/相电压、有效值/瞬时值。|
|静态温度|理论为工装环境温度T；范围T−5～T＋5℃。|
|板上电源轨|5V按±0.2V，填写“理论：5V；范围：4.8～5.2V”；其他电源轨默认标称电压±0.5V，例如15V为14.5～15.5V，24V为23.5～24.5V；只列板上实际存在的轨。|
|模拟VSP输入|输入等效±0.2V；回传电压直接判V，回传AD则按本工程实际系数换算上下限。|

以上是用户确认的方案默认值，不冒充已做样板统计验证。新项目有明确覆盖值时使用覆盖值。VAC/VDC低压分压节点的允许偏差须沿实际比例换算，不能直接套高压侧±5V；关系不明保留节点限值待确认。

VSP备注写程序采样系数及其单位、来源和换算关系，核对参考源、分压及是否偏置。线性V=k×AD时：理论AD=V目标/k，整数下限ceil((V目标−0.2)/k)，上限floor((V目标＋0.2)/k)；平均AD允许小数时保留连续边界，不套整数取整。换算系数和码值必须来自本工程有效配置，不复制其他板型参数。

同步配置与判限页及其他引用处，避免主表已确定而配置仍写待确认。

### 流程表

本用户使用针板工装：一次压合即连接全部配置测点。正式流程在开头写清端子/负载连接与一次压合/装夹，不把每个测点拆成接线步骤；扎针接线见测试点表，非扎针接线见配置。固定参考端、工装通道及供电/测量隔离关系在对应位置写清，流程引用。需要工装切换的激励、继电器和通信通道仍写明。

按测试状态分块，同一状态下能一起检测的信号集中在一行列全名称，例如“VAC、VDC、TEMP、U/V电流零点”，不能只写“检查采样”，也不一信号一行。用阶段栏或浅色底区分静态采集、输出组、拖动和结束；颜色辅助识别，阶段文字不可省略。仅在等待、激励、状态或通信对象变化时拆步骤。电流零点必须在输出停止/PWM关闭时测，不能为合并行而放进拖动阶段。

流程中的通信动作使用协议已定义的指令名称与必要参数，如“进入FCT”“选择组1”“拖动启停（停止）”；完整十六进制帧、字段偏移及解析放协议。名称不清时同步规范协议名称，不让流程与协议各起一个名字。流程每行只写执行动作、必要等待、该阶段信号和判定引用，源码解释、审查过程和待确认原因放独立说明。针板一次接通不代表全部项目同时激励或同时判定。


按第二步确认的顺序：供电等待3～5s、通信及版本 → 工装激励与静态检测 → 输出组1/2（必要时组3）→ 拖动 → 可选已确认故障检测 → 结束。具体条件服从电路正常吸合时序；零点采集不能排在通流之后。组1联动拖动不自动要求拆开。

步骤中写“施加/命令—等待—测量/读取—判断—下一状态”。需要共同保持的条件要讲清，例如电流环回路供电、电子阀测试负载、外部电阻和保留的通信口。流程完整覆盖装夹接线、上电、激励、测量/协议读取、判定、停止、撤激励、断电放电及松夹。扎针动作对应测试点表；非扎针项目在流程或配置与判限页给出连接和判据，不为保持对应而虚增针点。涉及通信的动作在协议中对应指令/字段。

模板来源与选择优先级见 [内置模板及来源](templates.md)。模板内原项目对象、针点、供电、字段及报文不作为新项目默认值。沿用用户现有模板，允许在原流程模板内添加阶段文字及浅色分块，不另起布局。保持工作表、列结构、合并区域、字体、边框、标色及打印设置；只扩展确需增加的内容。合并单元格启用换行后仍要检查行高，不缩小字号硬塞。修改以最新人工版本为基线，先备份，再检查导出文件，不能重跑旧脚本覆盖用户修改。

## 8 协议怎么随程序更新

优先继承现有命令和帧框架。编制目标方案时，按必测项定义所需真实回传字段和控制动作，优先扩展已有数据结构；缺少字段或命令时，先列能力缺口、影响和可选处理方式供使用者确认；确认采用扩展后才编制目标协议和软件修改清单，说明兼容要求，不声称当前程序已支持。实现核对时按已确认协议验收，不自行改变指令约定。

每个字段至少记录：命令、字节偏移、长度、类型、真实物理对象、单位、缩放、有效条件和异常/未完成含义。内部成员名有历史包袱时，明确其当前物理含义；不要只按变量名猜相位。

更新顺序：

1. 核对源/头文件当前字段顺序及实际赋值来源，建立“外部端子—采样通道—变量—报文偏移”映射。
2. 核对float大小、字节序、结构体填充、枚举/位域及目标编译设置。直接复制结构体时，sizeof才决定实际发出的字节数；不能套用桌面编译器结果。
3. 分别重算应用数据长度和整帧长度，复核发送缓冲及循环计数范围。不要把命令头3字节和外部帧头/校验混为一谈。
4. 明确请求和响应差别：哪些带参数、哪些回显组号、哪些带状态/故障；双电机不能继续沿用单电机长度。
5. 给典型请求和响应写完整十六进制例子，独立复核长度、互补字节和校验覆盖范围。
6. 更新工装解析器及其报文版本识别方式；继承既有版本机制，不自行另创指令。不兼容变化要明确新旧组合如何处理。
7. 同步测试点表的单位/判据和流程里的读取时机，避免协议写AD、工装仍按V比较。

编方案时即使已有业务固件，也要区分目标协议与旧FCT实现：旧字段缺失、单位不合需求或数据未更新时，先列出差异供使用者决定，不直接定目标定义或修改要求。核对实现或仅编当前固件操作说明时，按真实赋值来源报告，不能以目标要求冒充现状。

有成功应答不等于动作已完成，0也不天然代表正在运行。要能区分命令确认、检测窗口、最终结果以及对应电机故障。清错、退出、恢复机制按工程实际需要决定；无需要则明确不使用，不保留会导致工装等待的空承诺。
