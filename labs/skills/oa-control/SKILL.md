# OA 操作

使用本 Skill 目录内的脚本直连 Edge，不依赖 Playwright MCP 或浏览器扩展。安装、配置和验证范围见 [README.md](README.md)。

## 连接和确认

先运行 `node scripts/oa.mjs status`，复用已登录页面；未连接时 `node scripts/oa.mjs start` 打开专用 Edge。不要把 CDP 可连接当成 OA 已登录，也不要替换成 Chrome。按 URL/标题选页，标签序号可能变化。

默认由用户人工登录。需要登录时先在聊天中确认；本次明确要求“登录OA”视为本次授权，不重复询问。已经登录则直接工作。
用户明确需要无需现场操作的登录功能时，才阅读 [references/optional-login.md](references/optional-login.md)；这是可选参考，不是默认或推荐方式，启用与安全风险由使用者自行评估。不默认运行配置或保存凭据。

**正式发送或提交前，展示实际填写结果并等待本次明确确认。** “填日报/发起表单”不替代发送确认，用户对当前预览说“发送吧”即满足。查询、填写、核对可自行完成。
项目存在多个合理匹配时，列出编号、正式名称和版本请用户选择。用户确认后可将映射保存在本机 `.state/recent-projects.json`，下次优先按编号查询；新版本或歧义仍需澄清。
删除、撤回、审批等仅按用户当前明确指令执行，不能继承历史任务授权。

## 工作参考

- 通用查询与残留事项：[references/common-work.md](references/common-work.md)。
- 研发管理项目日报：[references/daily-report.md](references/daily-report.md)。
- 尚未记录的表单：先检查实际入口、控件及必填规则，完成真实任务后增加独立参考文件，并在这里添加路由。不要假设所有表单都与日报相同。

## 执行与结果

一次连接内合并相邻操作，用字段出现、预期 Frame URL 或结果行等可观察状态等待，减少反复输出整页。
表单可能在 `zwIframe`，列表在 `mainIframe`；输入值用 inputValue，编辑输入不在 innerText 中。
默认使用用户当天日期。工作内容允许润色成简洁的“动作、结果、剩余事项”，不增加未提供的完成结果；明日计划缺失时询问。
发送前核对日期、项目版本、内容、逐项工时和总工时，并记录本机预览与记录 ID。只点击一次发送；结果不明确先查已发，避免重试造成重复单据。
只有已发详情或明确系统成功提示才支持“已发送”，并不代表审批已结束。检查实际保存字段，不把编辑页填写当作保存或提交成功。
页面警告按当次真实情况说明；本次允许继续不等于未来统一允许。

运行数据、凭据、Cookie、浏览器 profile、客户项目和业务截图只留在本机，不能加入公开 Skill 或提交。脚本使用的站点和项目号由每个使用者自行配置，示例不是生产配置。
