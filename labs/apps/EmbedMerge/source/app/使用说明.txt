EmbedMerge 0.7.0 合并操作
  统一“新建比较”，两侧浏览器均可选择文件或文件夹，自动识别类型；两侧须同为文件或同为文件夹。
  默认直接修改原文件，保存、覆盖和删除前备份。勾选“创建独立副本”后才复制到任务目录操作。
  文件树右键支持向左/右复制文件或整个文件夹、删除左/右文件或文件夹。删除文件夹含被筛选隐藏的文件。
  复制文件夹按过滤规则合并，不删除目标多余文件；不复制 .git/.svn 等版本管理目录。
  工具栏“撤回文件操作 / 重做”保留最近50步复制、删除及单文件保存，重启后可恢复。
  文件夹页 Ctrl+Z 撤回文件操作，Ctrl+Y 或 Ctrl+Shift+Z 重做；Delete 删除当前选中侧。
  文本编辑器 Ctrl+Z 仍撤回文字编辑；文件操作撤回遇到相关未保存草稿或外部修改时拒绝覆盖。
  新操作会清除可重做分支；超过50步不再提供按钮撤回，备份文件继续保留，不会自动删除。
  蓝色选区背景及边界在差异底色和失焦后仍显示；文件标题旁显示选中字数/行数。
  老任务保持创建时的副本/原文件模式，不静默切换。

EmbedMerge 0.6.0 文件直接比较
  点击工具栏“对比两个文件”，或启动页“对比两个文件 · 直接保存”。
  选择左右两个文本文件，可位于任意目录且文件名不同；打开后直接进入文本比较。
  此模式不复制工程，编辑内容暂存缓冲区。Ctrl+S 保存当前侧；右上角保存两侧已修改内容。
  保存先将磁盘旧字节备份并校验，再写回所选原文件；备份失败或外部文件变化时拒绝覆盖。
  备份位置：EXE 同目录 data\tasks\<任务ID>\backups\<ref或test>\<左侧文件名>\<时间戳和ID>.bak。
  编辑与复制菜单中的“其他编辑操作…”提供“恢复 ref/test 备份”和“打开备份目录”。
  恢复备份先进入编辑区，检查后保存。任务页可恢复直接文件任务及草稿。
  原文件在其他工具中改动后，请先处理草稿并重新加载；文件删除或路径变为链接时拒绝保存。
  直接模式只允许访问选中的两个文件；支持最多 4 MiB 文本，保留原有编码、BOM 和换行。
  模型、MAT 和二进制文件继续使用工程副本模式；目录比较仍保持原件只读。

EmbedMerge 0.4 试用版

CS+ 配置比较（0.4）
  选择两个工程目录后自动扫描 .scfg 和 .mtpj；文件名不同也会按唯一关系配对、比较。
  顶部“CS+ 配置”页签进入结果；文件夹页也有配对数量和“查看配置结果”入口。
  双击 .scfg / .mtpj 优先打开配置视图；同路径文件仍可从“原文对比”进入文本编辑器。
  “单片机配置”按定时器、ADC、串口、系统与引脚等模块展示 ref/test 的配置选项。
  “定时器总览”并排列出模块、分频、周期；点击模块查看详细设置。
  2 ms / 2000 μs 等单位写法可归一为等值，保留原始显示值。此判断针对参数，不代表已验证功能等价。
  工作模式变化时单独提示。MTU4 与 MTU3/MTU4 等共用硬件可关联展示，需结合各自模式核对。
  “CC-RX 工程配置”按构建模式、通用/编译/汇编/链接/输出、文件级构建设置分组。
  默认值独立列出；不把默认值直接当作当前生效设置，不重建完整工具链继承关系。
  “依据”展开源文件、行号、原始选中项和输入/保存值。其他未翻译选项和未启用项可显式展开。
  不运行外部 HTML 预览。XML 读取与解析在 EmbedMerge 主进程内进行，沿用该进程的公司授权。
  配对顺序：手动指定 > 相同相对路径 > 唯一同名 > 同目录唯一类型 > 两侧唯一类型。
  多个候选无法唯一确定时不会按内容相似度猜测；在“配对关系”选择两侧文件后保存。
  手动配对随任务恢复；不改名、不移动工程文件。普通 C/H 等文件仍按相对路径比较。
  文件树保留按路径的排列，故改名文件仍可能显示单侧；CS+ 配置结果已单独按配对计算。
  配置视图包含未保存工作草稿；草稿与磁盘冲突时明确报错，刷新按内容版本更新。
  此页当前只读；没有逐项写回 XML 的操作。需要修改时使用 CS+，或同路径文件的原文工作副本。

文本比较与保存（0.4）
  双向复制箭头默认位于左右代码中间，对齐实际差异块并随滚动、分隔栏调整更新。
  绿色表示 test 新增，红色表示 ref 删除，黄色表示双侧修改；代码区保留逐字与逐行差异底色。
  点击 ← 将对应 test 差异块复制到 ref，点击 → 将 ref 差异块复制到 test。只改工作缓冲区，可撤销。
  左侧编号列表默认隐藏；“详细差异列表”可以显式展开。顶部仍保留对应单行复制操作。
  左右可直接输入、选中、复制、剪切、粘贴。支持 Ctrl+C/X/V，也提供“更多”和编辑器右键菜单。
  右上角“💾 保存”保存当前文件两侧已修改的工作副本；Ctrl+Shift+S 同效，Ctrl+S 保存当前侧。
  “×”关闭文件页；返回文件夹、切换任务或进入配置页时，有修改会提示保存、保留草稿或取消。
  关闭整个程序同样支持保存后退出或保留草稿；没有修改时直接关闭。原始工程仍保持只读。

启动
  双击 release\EmbedMerge\EmbedMerge.exe，或本目录 Launch-EmbedMerge.cmd。
  第一次点击“打开 fixtures 示例”，使用人工协议/参数样例体验。
  主程序稳定名称 EmbedMerge.exe；整体移动 release\EmbedMerge 文件夹时保持内容完整。
  不需要管理员权限。启动异常有弹窗，日志在 EXE 同目录 data\logs\embedmerge.log。

基本操作
  文件夹页：左右对应项共享行高、展开状态与滚动容器；缺失侧留空。
  目录默认折叠；Ctrl+Shift+E 全部展开，Ctrl+Shift+W 全部折叠，也可点击工具栏按钮。
  “类型过滤…”配置常见无关文件；新建任务中也可先配置。勾选即排除，规则随任务保存。
  默认排除：SmartManual Docs、PDF/Office、网页/生成报告、图片音视频、编译二进制/中间文件及生成缓存。
  保留生成的 C/H、业务模型/MAT/Bus、脚本、XML/JSON 工程配置及链接脚本。
  支持额外扩展名和目录；不支持通配路径。计数按两侧被排除的文件或整目录入口计算，不是递归文件数。
  排除内容不进入新副本、比较和 AI 文件工具。已有副本不删除，未保存内容被规则排除时会阻止应用。
  关闭规则会从原件补齐缺失副本，已有工作副本保持原版本和编辑，不会以原件静默覆盖。
  双击文件打开全文比较；Enter 也可打开选中文件。
  默认全文；可勾选折叠未变。F7/F8 上一/下一处差异。
  左右均可直接编辑，Ctrl+S 保存当前侧，Ctrl+Z 撤销。
  “复制此块”只替换当前差异块的目标缓冲区，可撤销，不自动保存。
  中间差异块箭头提供双向复制；可选的详细差异面板保留逐块、逐行定位操作。
  缺失侧以空位表示，复制后立即重划差异块，所有复制均可撤销。
  “更多”提供整文件文本复制、所选文本复制、备份恢复、重新加载和换行选择。
  整文件文本复制保留目标编码/BOM/换行；不是磁盘原样字节覆盖。
  文件右键可记保留/忽略/待处理/已处理；审阅仅记录，不修改文件。
  文件变化后旧审阅记录标为过期。次要差异是保守 token 显示启发式，不是功能等价证明。
  模型/MAT 也可保留、忽略、待处理并填写备注；按输入版本标记审阅过期，不尝试当文本读取。
  #define、字符串、已识别的代码生成/静态检查指令不会按普通注释忽略；未知注释仍须人工核实。

任务与文件
  原始 ref/test 只读；每次创建任务，复制到 data\tasks\<id>\work\ref 与 work\test。
  顶部显示原始目录，鼠标悬停可查看工作目录；↗ 打开各侧工作副本目录。
  编辑器中的未保存内容参与比较；自动保存的是草稿，不是工程文件。
  任务页可恢复工作副本、未保存草稿、审阅和本地对话。
  保存前检查磁盘 SHA-256，发现外部变化即拒绝覆盖。更多菜单可显式丢弃当前侧草稿并重载。
  每次有内容保存前写入 backups\<side>\<relative path>\ 时间戳 .bak，可恢复到缓冲区再检查保存。
  保存核验实际字节，保留 UTF-8/GB18030/带 BOM 的 UTF-16 LE/BE 及原换行。
  混合换行文件修改后须明确选择统一 LF/CRLF；编码不能无损往返时拒绝保存。
  某些公司文件系统不支持同目录原子替换。此时保留 .recovery 及备份，使用核验写入，并显示说明。
  这一路径不具备断电原子性；出现中断可从恢复副本/备份检查恢复，不静默宣称成功。
  拒绝符号链接、目录联接、路径越界和 NTFS 替代数据流。
  当前限制：20000 个目录项、单文件副本 128 MiB、文本 4 MiB；排除 .git/.svn/node_modules/.npm-cache。

Codex（按需）
  点击右上 Codex；首次提问自动连接，也可主动点击连接；安装官方 Codex CLI 后可自动发现 codex.exe。
  通过“个人账号登录”打开官方 ChatGPT 登录页面；不读取或复制凭据文件，不要求共用 API Key。
  连接只查询版本和登录状态；发送问题后才调用模型并附上当前选区/差异位置、两侧版本。
  按需用受任务边界约束的 project_files 列出/搜索/读取宏、调用方与编译配置。
  普通问题只读。需要修改时，在问题中明确修改要求，并勾选本轮授权。
  AI 修改仍是未保存草稿；先人工查看差异，再保存。目标已有未保存编辑时，AI 修改会被拒绝。
  可连续追问，停止当前轮，配置文件工具次数、输出字符和轮次超时；这些不是费用硬上限。
  文件读取缓存按内容 SHA-256 和缓冲区 revision 失效；工具步骤、版本和行号在侧栏展开。
  当前使用本机 Codex 默认模型/额度。Windows 使用官方只读沙箱；禁用 shell/外部 MCP/连接器，文件范围由应用工具强制检查。
  App Server / dynamicTools 协议存在实验字段；不兼容版本明确报错，不自动放宽到无沙箱。
  本地对话保存在任务，运行期间复用官方临时 thread；重启后用有限本地历史重建上下文。
  标准强度默认 medium；可切换快速 low 或深入 high。复用会话时不重复发送全段本地历史。
  等待时显示连接、发送、服务端处理和工具阶段、累计/静默时间；可停止。任务保存首段输出/总耗时。
  官方说明 App Server 认证可用于本地/开源应用；商业/托管场景另核实 Sign in with ChatGPT 条件。
  官方资料：https://developers.openai.com/codex/app-server/
            https://learn.chatgpt.com/docs/permissions

MATLAB 与亿赛通
  .mdl/.slx 使用 R2024b 官方 slxmlcomp.compare；可按需打开 visdiff 官方窗口。
  创建/恢复任务和重新比较时，默认批量调用 MATLAB，自动更新文件树颜色；输入版本未变复用缓存。
  .m 使用官方 visdiff 文本报告，并保守区分独立注释/日期、空白候选与代码变化，不执行脚本。
  模型默认过滤结果为空时，另保留官方 unfiltered HTML 报告；只对已识别的显示/日期项标次要候选。
  报告格式未知、覆盖不完整、缓存过期、读取失败分别明确显示，不能以零条过滤差异判为一致。
  右键“查看已计算的 MATLAB 对比结果”显示本地摘要；“打开 MATLAB 官方比较窗口”请求可见 visdiff。
  官方无差异时可能只显示结果提示，不出现差异树；调用返回不等于已核实窗口存在或功能等价。
  .mat 独立用自定义 MATLAB MAT/Bus 遍历，或在官方 visdiff 变量窗口查看。
  两条路径的来源在结果中区分，不把自定义字段算法称为官方模型比较。
  内部比较树路径不是画布块路径；0 条可见差异不代表功能等价。
  支持有限的常见数值、struct/cell、Simulink.Bus/BusElement；深度/元素/内存超限及未知类型标未完整核实。
  .sldd 暂待接入，模型合并暂缓。不会自动编译、仿真或运行整个工程初始化。
  原生文件读取入口在文件树右键菜单，必须确认公司已授权 MATLAB 读取该文件。
  MATLAB 仅取得字节；普通文本的比较仍由本地 Monaco/jsdiff 执行。
  来源、读取时间、原件指纹及缓存位置记录于任务，取得受保护/非文本内容仍明确失败。
  MATLAB exe 默认查找 D:\App\matlab\R2024b 与 C:\Program Files\MATLAB\R2024b；也可填写完整路径。
  后台 -batch 不显示桌面；“显示官方比较窗口”连接 R2024b 共享 AutomationServer，首次无可用会话时才启动桌面。
  连续打开其他文件复用同一 MATLAB；关闭 EmbedMerge 后保留手动启动的 MATLAB 桌面，重新打开应用仍可连接。
  普通启动且未启用 AutomationServer 的 MATLAB 不会被接管；应用最多另起一个专用共享桌面。
  旧比较页自动关闭尚待 R2024b 安全接口验证，目前可手动关页；不强制关闭用户模型编辑器或未保存工作。
  官方窗口请求超过 5 分钟停止等待，不因此重开 MATLAB；仍在处理时拒绝下一请求，防止堆积。
  窗口请求的停止只停止应用等待，MATLAB 可能仍完成该请求；后台计算停止会终止应用的后台任务。
  读取失败为黄底黑字、黑色 ! 和边框，与实际差异红色、单侧紫色、次要差异色分开；选中后仍保留失败样式。
  Windows 启动器提前返回 0 时继续等候交互比较结果，不再误报 MATLAB 已退出。每次任务保留独立日志。
  MATLAB 批量比较逐文件保存证据并更新颜色，中止/超时不丢失已完成结果；失败结果重新比较会重试。
  后台总时限按数量为 5～30 分钟；可随时停止。冷启动准备期间也支持取消，不会延后继续启动。
  同字节文件快速显示一致，并明确来源为本地字节核对；不因此推断外部数据、模型依赖或运行行为。
  Bus 元素增删/顺序及字段变化按名称对齐，显示所在对象路径、两侧存在性、类型和维度。
